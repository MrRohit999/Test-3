# KARMIX TECHNOLOGY Website

A responsive, static website prepared for GitHub Pages.

## Included
- `index.html` — website structure and content
- `assets/style.css` — responsive styling
- `assets/script.js` — mobile menu, current year, and email enquiry form

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload `index.html` and the `assets` folder to the repository root (keep the folder structure).
4. Commit the changes.
5. In GitHub, open **Settings → Pages** and select your publishing branch and `/ (root)` if not already configured.
6. Open the GitHub Pages URL after deployment finishes.

## Important notes
- The enquiry form opens the visitor's default email application and prepares an email to `karmixtechnology@gmail.com`. It does not send automatically and does not require a server.
- Replace the email address and phone number in `index.html` if your public contact details change.
- The website intentionally does not include LabVIEW branding/name, .NET, Python, or C++.
- Google Fonts require an internet connection. The website layout and illustrations are CSS-based; no separate image downloads are required.
